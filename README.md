## 版本记录与回退

本仓库使用 Git 版本管理。每次在 GitHub 上保存文件修改或在本地执行 `git commit`，都会产生可追溯的提交记录；本地尚未提交的编辑不在版本历史中。

- 查看历史：仓库的 Commits 页面，或 `git log --oneline`。
- 比较差异：`git diff`（未提交修改）或 `git show <提交SHA>`（指定提交）。
- 撤销某次已提交修改：`git revert <提交SHA>`，然后 `git push`。这会新增一条撤销提交并保留历史；遇到冲突时先解决冲突再继续。
- 每次提交只处理一个明确主题，使用具体说明，例如 `docs: 更新沟通风格偏好`。

## 本地同步

首次下载（需先安装 Git）：

```bash
git clone https://github.com/steveli33/ai-personal-profile.git
cd ai-personal-profile
```

日常更新：

```bash
git pull --ff-only
# 编辑 README.md，确认内容后提交
git add README.md
git commit -m "docs: 更新个人档案"
git push origin main
```

首次提交前，如 Git 提示缺少身份，请按提示配置自己的 `user.name` 和 `user.email`；可使用 GitHub 提供的 noreply 邮箱。推送时使用 GitHub 支持的登录方式，例如 GitHub CLI、凭据管理器或 SSH。
